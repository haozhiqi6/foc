# foc
基于 STM32 的 SimpleFOC 闭环力控旋钮  以 STM32F103C8T6 为主控，将 SimpleFOC 磁场定向控制算法移植到 STM32，驱动无刷电机实现闭环力矩控制。  硬件用 AS5600 磁编码器读角度，TIM2 输出三路 PWM 驱动三相桥；上电自动完成电机对齐与编码器标定，之后每 1ms 采样角度与转速，实时解算 q/d 轴电压完成闭环。  控制分两种模式：慢转时是档位模式，每 10° 一个磁吸档位，带滞回与位置阻尼闭环，手感清晰；转速超过 100rpm 后自动进入旋转模式，先给助力，再用 1 秒趋势窗判断转速是否自然衰减，衰减则 20 秒内平滑撤力，降到 20rpm 以下回到档位模式。  串口以 100Hz 输出转速与 q 轴电压，便于调参。
